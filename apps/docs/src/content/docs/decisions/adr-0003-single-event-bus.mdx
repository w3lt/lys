## Context

Replay and live delivery were implemented twice, and the two paths disagreed
about ordering after a reconnect.

## Decision

A single in-process event bus serves both replay and live subscribers,
retaining the last two hundred events per session.

## Consequences

Ordering became consistent, but the design assumed the backend was the only
credentialed component and that assumption no longer holds.
