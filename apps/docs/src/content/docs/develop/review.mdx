- the final checklist in `CONTRIBUTING.md`

## Merge request review

Use the merge request review standard when reviewing a proposed change before it
merges. Its core expectations are:

- establish the stated purpose and review boundary first
- review the changed lines and the directly involved parts
- report findings only
- record every validation command actually run

## Full code review

Use the full code review standard when auditing an existing area of the codebase
independently of a pending change. It requires an explicit review target and an
inventory of the repository-owned items in scope.

## Reviewer mandate

The review standards are explicit that reviewers:

- report findings only
- do not modify the implementation under review
- may run validation commands
- must not weaken an active standard to make a change acceptable
