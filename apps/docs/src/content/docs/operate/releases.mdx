## Docs deployment

The repository contains one checked-in publication workflow today:

- workflow: `.github/workflows/deploy-docs.yml`
- trigger: pushes to `main` and manual dispatch
- build command: `pnpm --filter @lys/docs run build`
- artifact directory: `apps/docs/dist`
- deploy target: GitHub Pages

That workflow is the only evidenced automated release path in this repository.

## Desktop packaging

The Tauri config declares desktop bundle metadata and package targets, which is
enough to show packaging is intended:

- product name: `Lys`
- app identifier: `com.w3lt.lys-desktop`
- bundle targets: `all`

The repository does not currently prove an automated desktop signing,
notarization, or publication workflow.

Desktop artifact signing, release publication, and a canonical end-user release
process are not documented yet.

## Versioning status

The checked-in workspace manifests are currently versioned `0.1.0` for:

- the repository root package
- `@lys/docs`
- `@lys/backend`
- `@lys/desktop`
- `@lys/protocol`
- `@lys/share`

There is not yet a canonical release log or a tag-based release history in the
repository.
