## 0.7.2

**Fixed** — Diagnostics bundles redact provider metadata. Bundle contents moved
from a denylist to an allowlist, so a field reaches a bundle only once it has
been classified as safe to disclose. See
[RFC-0011](/rfcs/rfc-0011-diagnostics-bundle-redaction/).

## 0.7.1

**Changed** — Forward-only migrations applied at startup. The backend applies
pending migrations when it opens the store and refuses to open a store newer
than the binary understands. Downgrading to an earlier build against a migrated
store is now refused with a clear message rather than attempted; recover from a
copy instead. See
[ADR-0009](/decisions/adr-0009-forward-only-migrations/).

## 0.7.0

**Added** — Host-issued credential handles. The Tauri host is now the only
component that reads the operating-system keychain, and the backend receives
short-lived, provider-scoped handles. See
[ADR-0007](/decisions/adr-0007-credential-handles/) and
[RFC-0009](/rfcs/rfc-0009-scoped-credential-handles/).
