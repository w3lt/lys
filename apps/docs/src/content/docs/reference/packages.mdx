The current workspace contains three apps and two shared packages.

## Workspace map

| Project         | Kind    | Current role                                                                   |
| --------------- | ------- | ------------------------------------------------------------------------------ |
| `@lys/desktop`  | app     | React UI plus Tauri frontend bindings                                          |
| `@lys/backend`  | app     | Fastify backend serving health, LLM, chat, and conversation history endpoints  |
| `@lys/docs`     | app     | Astro/Starlight engineering handbook                                           |
| `@lys/protocol` | package | Shared route constants, request and response schemas, and chat event contracts |
| `@lys/share`    | package | Shared conversation and message schemas                                        |

## Project notes

### `@lys/desktop`

- Entry UI: `src/App.tsx`
- Native host: `src-tauri`
- Important runtime dependencies: React, Zustand, Tauri API bindings,
  `eventsource-parser`
- Runtime, Model, and Generation settings share application state. Model controls
  call the backend; generation edits are saved through Tauri and sent with chat requests.

### `@lys/backend`

- Entry point: `src/index.ts`
- Framework: Fastify
- Important runtime dependencies: `@fastify/sse`, `@lmstudio/sdk`, `openai`,
  `fastify-type-provider-zod`

### `@lys/docs`

- Content root: `src/content/docs`
- Framework: Astro with Starlight
- Builds the static handbook published by the checked-in GitHub Pages workflow

### `@lys/protocol`

- Re-exports API route modules, constants, and HTTP helpers, including conversation
  list, get, rename, delete, and missing-conversation contracts
- Defines the backend loopback host and port constants used by both backend and
  desktop

### `@lys/share`

- Exports Zod schemas and inferred TypeScript types for conversations and
  messages
- Used by both backend persistence code and desktop chat state

## What is not in this workspace map

- No separate provider adapter package
- No standalone persistence package
- No generated SDK package for backend consumers
