## Shared foundation

The top-level construction rules are defined in:

- `docs/CODE_STANDARDS.md`
- `CONTRIBUTING.md`
- `docs/JSDOC.md` for repository-owned JavaScript and TypeScript declarations in
  its scope

## Finding rule identifiers

Use the repository search command referenced by `docs/CODE_STANDARDS.md`:

```sh
rg -n '^(### [A-Z]+-[0-9]{3}|# )' docs/code_standards
```

That command lists stable rule headings such as `FUNC-###` or `TYPE-###`.

## Current limitation

This repository does not currently generate a flattened rule mirror for the docs
site. The source of truth remains the Markdown files in `docs/`.
