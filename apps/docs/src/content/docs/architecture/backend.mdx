## Responsibilities

The backend is the single owner of durable session state. It accepts commands
from the Tauri host, resolves them against the session store, and emits every
resulting state change as a typed event. Nothing else in the system writes to
the session database, and no component derives session truth from its own cache.

- Session lifecycle: creation, resumption, truncation, and deletion.
- Provider orchestration, including retry, cancellation, and budget accounting.
- Event publication over the shared protocol described in
  [SSE events](/reference/sse-events/).

## Boundaries

The backend never renders, never reads the operating-system keychain directly,
and never talks to a provider without a credential handle issued by the host.
That split is the subject of
[ADR-0007](/decisions/adr-0007-credential-handles/).

## Data and control flow

Each command is handled inside a single write transaction. The stream task
subscribes to the resulting change feed rather than to the command itself, which
is what keeps replay and live delivery on the same code path.

```rust title="crates/backend/src/session/stream.rs"
// Emission follows commit; never precedes it.
pub async fn publish(&self, cmd: Command) -> Result<EventId> {
    let tx = self.store.begin().await?;
    let change = tx.apply(cmd).await?;
    tx.commit().await?;

    self.bus.emit(Event::from(change), Retention::Replayable(200))
}
```

## Failure behaviour

| Condition             | Detected by       | Behaviour                                                                              |
| --------------------- | ----------------- | -------------------------------------------------------------------------------------- |
| Provider timeout      | call deadline     | Emits a failed turn; the session stays writable and the message is retryable.          |
| Malformed frame       | protocol decode   | Frame dropped, stream closed with a typed error; the client resubscribes and replays.  |
| Store lock contention | write transaction | Bounded retry, then a surfaced error. The backend never abandons a partial write.      |
| Host disconnect       | channel close     | In-flight provider calls are cancelled and credential handles are dropped immediately. |
