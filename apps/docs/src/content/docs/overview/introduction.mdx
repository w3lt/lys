Lys is a local-first desktop chat application under active development. Today
the repository contains three applications, two shared packages, and one
tooling package:

- `apps/desktop` is the user interface: React 19, Vite, Zustand, and a Tauri 2
  host.
- `apps/backend` is the local HTTP backend: Fastify, Server-Sent Events, model
  inventory via the LM Studio SDK, and chat completions through an
  OpenAI-compatible client.
- `apps/docs` is this Astro/Starlight handbook.
- `packages/protocol` defines shared route constants and validation schemas.
- `packages/share` defines shared conversation models.
- `scripts` keeps the release version in the root `VERSION` file in step with
  every package and desktop manifest.

The root workspace is managed with `pnpm`, and the checked-in package manager
pin is `pnpm@11.17.0`.

## Runtime shape

One chat turn currently crosses these boundaries:

1. The desktop store submits a prompt to `POST /api/v1/chat`.
2. The backend creates or continues a conversation, inserts the user message
   and an empty assistant row in SQLite, then starts streaming SSE events.
3. The desktop reads typed stream events and updates its local presentation
   state from them.

The backend persists each assistant delta before sending it and records the
reply's final status, so a stored conversation can be reopened from the
desktop's conversation history and continued.

The current public protocol surface is small: a health route; LLM inventory,
health, load, and unload routes; conversation history routes to list, read,
rename, and delete; and the chat stream.

## What this handbook is for

Use this handbook to understand current repository structure, runtime behavior,
contributor workflow, operations, and shared contracts. The decision, proposal,
and release registers are visible placeholders until real records exist.
