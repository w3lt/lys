contract.

## Event types

| Event               | Meaning                                                       | Since |
| ------------------- | ------------------------------------------------------------- | ----- |
| `session.created`   | A new session exists and is writable.                         | v1.0  |
| `message.appended`  | A message was committed to the store.                         | v1.0  |
| `message.delta`     | A fragment of an in-progress assistant message.               | v1.0  |
| `turn.failed`       | A turn ended without a usable result; carries a typed reason. | v1.1  |
| `session.truncated` | Messages after a point were removed by an explicit write.     | v1.2  |
| `stream.resumed`    | Replay finished; subsequent events are live.                  | v1.2  |

## Compatibility

New event types and new optional fields are additive and do not change the major
version. Removing an event, renaming a field, or narrowing an accepted value
requires an ADR and a deprecation notice on this page for one release before the
change lands.
