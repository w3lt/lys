## Summary

When a provider call fails for a reason that a different provider would not
share — a rate limit, a regional outage — attempt a configured alternative
before failing the turn.

## Open questions

This draft is incomplete. The unresolved questions are:

- Which failures are eligible. A timeout may mean an overloaded provider or a
  malformed request, and the two must not be treated alike.
- What the reader is told. A silent substitution changes which model answered
  without saying so, which is not acceptable.
- How budget accounting attributes a turn that touched two providers.

## Motivation

A single provider's rate limit currently ends the turn even when an equivalent
provider is configured and idle. The failure is recoverable, and the recovery is
mechanical.
